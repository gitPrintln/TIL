# 암호 기법 분류 핵심 정리

암호 기법은 크게 **고전 암호의 조작 원리(치환·전치)**와 **현대 대칭키 암호의 처리 단위(블록·스트림)** 관점으로 나누어 이해할 수 있습니다.

---

## 1. 치환 암호 vs. 전치 암호 (문자·기호 조작 원리)

| 구분 | 치환 암호 (Substitution Cipher) | 전치 암호 (Transposition Cipher) |
| :--- | :--- | :--- |
| **핵심 원리** | 평문의 문자·기호를 **다른 문자·기호로 대체** | 평문의 문자 **순서(위치)만 재배열** |
| **문자 구성** | 원래 평문에 없던 기호·다른 글자가 등장 | 평문에 있던 글자 집합과 빈도는 그대로 유지 |
| **대표 예시** | 카이사르(Caesar) 암호, 아핀 암호, 비제네르(Vigenère) 암호 | 레일 펜스(Rail Fence) 암호, 열 전치(Columnar Transposition) 암호 |
| **보안 약점** | 단일 치환은 빈도 분석에 취약, 다중 치환도 키 재사용·패턴 노출에 한계 | 애너그램·빈도 분석 등으로 글자 집합과 규칙성이 드러나기 쉬움 |

> **참고**: 현대 암호(예: AES)는 이 두 가지 아이디어—대체/혼돈(**Confusion**)과 재배열/확산(**Diffusion**)—를 라운드 단위로 반복 결합해 안전성을 높입니다.

---

## 2. 블록 암호 vs. 스트림 암호 (현대 대칭키 처리 단위)

| 구분 | 블록 암호 (Block Cipher) | 스트림 암호 (Stream Cipher) |
| :--- | :--- | :--- |
| **처리 단위** | 평문을 **고정 길이 블록**(예: 128비트)으로 나누어 암호화 | 평문을 **비트 또는 바이트 단위(연속 흐름)**로 암호화 |
| **동작 방식** | 블록 단위 변환 + **운영 모드(CBC, GCM 등)**로 연쇄·인증 처리 | 키와 초기화 벡터(IV/Nonce)로 **키스트림(Keystream)**을 생성한 뒤 보통 **XOR 연산**으로 결합 |
| **대표 예시** | AES, ARIA, SEED | ChaCha20, RC4(취약성으로 현재는 지양) |
| **장단점 및 용도** | 정형 데이터·파일·디스크·패킷 암호화에 적합하며, 패딩이나 운영 모드 설계가 필요 | 실시간 통신·저지연 스트리밍·경량 환경에 유리하며, **키스트림 재사용 시 치명적 취약점** 발생 |

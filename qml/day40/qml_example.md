## 산업용 양자 컴퓨팅 도입 로드맵

- 개념 검증(PoC) 단계
- 목표: 업무 한 가지와 평가 자료를 정하고 동일한 입력에서 고전 기준 방법과 양자 접근을 실행합니다. 예를 들어 배송 세 곳의 순서 결정에서는 예측 시간의 오차, 배정 제약, 경로 비용과 실행 시간을 각각 측정합니다.
- 수행 항목:
입력의 단위·범위와 누락 처리 기준을 정합니다.
목적함수와 제약을 문장과 수학적 모형으로 표현합니다.
작은 문제의 정확 해와 업무용 고전 기준 방법을 준비합니다.
동일한 시간·평가 예산에서 반복 실험합니다.
실패한 해와 비용을 포함해 결과를 기록합니다.
- 산출물: 문제 정의서, 입력 데이터, 실행 코드, 환경 정보, 기준 방법의 결과, 실행 로그와 다음 단계의 진입 조건입니다.
하이브리드 운영 단계 목표: 업무 시스템의 일부 요청을 양자 실험 경로로 보내고 결과의 유효성과 지연을 관찰합니다. 기존 운영과 동일한 입력 시점·조건으로 시험해야 합니다.
- 수행 사례: 금융에서는 동일한 시험 거래의 사기 점수를 비교합니다. 제조에서는 생산 일정 추천을 생성한 후 선행 관계와 설비 용량을 검사합니다. 물류에서는 추천 경로의 배송 누락·중복과 차량 용량을 확인합니다. 결과가 기한을 초과하거나 제약을 위반하면 사전에 정한 고전 계산 경로와 업무 승인 절차를 적용합니다.
- 하이브리드 운영 단계 산출물: API 입력·출력 명세, 호출 실패 처리, 비용 한도, 결과 검증기, 모니터링 기록과 운영 책임자입니다.
- 규모 확대와 장기 운영 단계 목표: 검증된 사용 사례의 규모를 확대하고 장치·알고리즘 변경에 따라 성능과 비용을 재평가합니다. 필요한 논리 큐비트 수, 오류율, 회로 깊이와 반복 횟수는 대상 문제에서 추정합니다.
- 전환 사례: 분할한 일정 문제의 부분해를 통합하거나 재료 계산의 활성 공간을 확대합니다. 확대 과정에서 목적함수의 개선량, 제약 위반률, 전체 처리 시간과 운영 비용이 허용 범위를 유지하는지 확인합니다. 연구 결과를 사업 목표로 연결하는 범위는 실측 자료를 바탕으로 정합니다.
- 규모 확대와 장기 운영 단계 산출물: 규모별 자원 추정표, 서비스 수준 기준, 재평가 주기, 장치 교체 계획과 투자 판단 자료입니다.

## 산업 도입을 위한 Best Practice
- 문제와 기준 방법을 함께 정의합니다: 최적화는 동일한 목적함수·제약으로 평가하고, 분류는 동일한 시험 데이터로 평가합니다. 작은 예제의 완전탐색은 정확성 기준으로 사용합니다. 큰 문제에서는 실제 사용 중인 솔버와 휴리스틱을 기준에 포함합니다.
- 전체 비용과 실패를 기록합니다: 한 번의 회로 실행 시간에 데이터 준비, 컴파일, 장치 대기와 후처리 시간을 더합니다. 유효한 해가 나오지 않은 실행도 포함해 업무 요청 한 건당 비용과 성공률을 계산합니다.
- 모형의 범위를 명시합니다: QUBO는 이진 최적화의 표현 방법입니다. 분자 계산·분류·키 분배는 각 기술에 맞는 입력과 평가가 필요합니다. 배송 예제에 차량 용량이나 시간창을 구현하지 않았다면 결과를 사용할 때 그 범위를 유지합니다.
- 규모와 반복 조건을 함께 늘립니다: 후보 수, 회로 층수, 측정 횟수, 최적화 평가 횟수를 각각 바꿔 병목을 찾습니다. 여러 조건을 동시에 바꾸면 성능 변화의 원인을 파악하기 어려워집니다.
- 협업의 산출물을 정합니다: 외부 파트너와 데이터 사용 범위, 모델·코드의 소유권, 재현 가능한 실행 기록, 비용 상한과 종료 조건을 합의합니다. 보고서에는 실행 환경과 업무 지표를 함께 남깁니다.

## 결론: 지금 기업이 선택해야 할 전략 방향
- 우선 검토할 업무: 현재 계산 병목이 측정되고, 작은 문제로 축소할 수 있으며, 정답 또는 업무 기준 결과를 확보할 수 있는 과제를 선택합니다. 물류·일정·투자 선택·이상 탐지는 이러한 조건을 점검할 수 있는 후보입니다.
- 중기적으로 준비할 사항: 실측 데이터, 평가 체계, 하이브리드 인터페이스와 장애 대응을 확보합니다. 분자·재료 연구에서는 계산의 오차가 실험적 의사결정에 미치는 영향을 함께 검증합니다.
- 장기적으로 확보할 역량: 업무 모형을 양자 자원으로 연결하는 능력, 결과를 해석하는 도메인 지식, 자원·비용 추정과 재현 가능한 실험 체계를 축적합니다. 투자 확대는 품질·시간·비용·운영 안정성의 근거로 결정합니다.

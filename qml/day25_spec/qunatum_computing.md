## 양자컴퓨터 : 고전컴퓨터에서 해결하기 어려운 문제들을 독특한 양자적인 성질을 사용하여 훨씬 빠르게 해결할 수 있는 컴퓨터

## 고전 컴퓨터의 한계
#### 1. 무어의 법칙의 한계
- 고전 컴퓨터는 연산의 기초 단위로 비트(Bit, Binary Digit)를 사용
- 비트는 0과 1 데이터를 표현하는 최소 단위이며,
- 컴퓨터의 모든 정보는 이진법(Binary) 기반으로 저장되고 연산됨
- 트랜지스터(Transister)
- 고전 컴퓨터는 전기의 흐름을 이용하여 0과 1을 구별(전기가 흐르면, on(1), 흐르지 않으면, off(0))
- 트랜지스터 개수가 증가하면 더 많은 연산을 처리 -> 컴퓨터 성능이 향상

#### 2. 에너지 비효율성
- 연산 속도 증가 = 에너지 소모 증가
- 컴퓨터가 연산을 수행할 때 소모된 에너지는 열로 변호나됨
- 고성능 연산을 수행할수록 더 많은 에너지를 소비하며, 이에 따라 발열 문제도 심각해짐
- 냉각팬, 수냉 시스템 등으로 발열 감소 시도하지만, 근본해결책은 아님
- 랜다워의 원리(Landauer's Principle)
- 정보를 지우는 행위는 열역학적으로 엔트로피를 증가시킴
- 1비트의 정보를 지울 때 발생하는 최소한의 열에너지가 있음
- 고전 연산은 비가역적, 따라서 정보 손실이 발생함 - 열로 배출

#### 3. 복잡한 데이터 처리의 한계
- 고전 컴퓨터로 풀기 어려운 문제들(암호해독, 신약개발, 신소재 연구 등)
- 지수적 폭발: 변수 증가에 따른 연산 조합이 지수적으로 폭발하여 인류의 수명 내 계산 불가능
- 차원의 저주: 고차원 비정형 데이터(영상, 음성)를 평면적(0,1)으로 처리하여 중요한 패턴을 놓치거나 엄청난 학습시간 소요
- 확률적으로 불확실한 문제: 고전컴퓨터는 확정된 값(0,1)로만 처리, 복잡계 예측시 반복적 시뮬레이션에 의존

#### 문제 해결 방식의 변화
- 하드웨어 물리적 한계: '무어의 법칙'의 종말
- 에너지 효율 변화: 비가역 -> 가역
- 연산방식의 변화: 순차처리 -> 동시 탐색
- 시뮬레이션 방식의 변화: 자연을 닮은 계산기

## 양자(Quantum)
- 미시세계의 물질과 에너지가 따르는 독특한 물리적 특성을 이해하기 위한 개념
- 양자는 특정한 하나의 물질을 의미하는 것이 아니라, 극소 규모의 물질과 에너지를 포괄적으로 지칭
- 전자, 원자, 광자, 중성자, 양성자, 쿼크 등 양자상태를 가질 수 있는 대상

## 양자 성질 - 중첩(Superposition)
- 하나의 상태로 확정되기 전까지 여러 상태가 동시에 존재하는 현상
- 미시 세계에서 모든 입자는 측정이나 환경과의 상호작용이 없을 때 중첩상태로 존재
- 양자는 측정되기 전까지 여러 상태가 존재할 수 있지만 측정하는 순간 하나의 상태로 확정
-> 양자컴퓨팅에서 중첩현상은 탐색할 후보군을 넓혀 주는 역할

## 양자 성질 - 얽힘(Entanglement)
- 두 개 이상의 양자가 연결되어, 한 입자의 상태가 변하면 즉시 다른 입자의 상태도 변하는 현상
- 하나의 양자 상태가 결정되면 다른 양자상태도 즉시 전해지는 현상
-> 얽힘은 큐빗 간 복잡한 양자적 상관관계를 형성하여, 고전컴퓨터로 표현, 계산 하기 어려운 양자 상태를 구현하고 활용할 수 있게함

## 양자 성질 - 간섭(Interference)
- 중첩된 양자 상태의 확률진폭이 서로 보강되거나 상쇄되어, 측정 결과 확률이 달라지는 현상
- 정답 상태는 강화(보강간섭), 오답상태는 소멸(상쇄간섭)
-> 원하는 계산결과의 측정확률을 높이고 불필요한 결과의 측정확률은 낮춤

## 터널링
- 장벽을 넘지 않고 통과
- 양자 어닐링 컴퓨터에서 활용

## 복제 불가능
- 양자암호(QKD)에 활용

## 큐비트 : 0과 1을 동시에 가지며 여러 큐비트가 강하게 연결되어 빠른 연산 가능

## 양자게이트
- 양자컴퓨터는 양자 게이트를 통해 큐비트의 상태를 변환하고 연산 수행
- 즉 큐비트의 중첩과 얽힘 상태를 조작하여 연산 수행
- Ex) X, Y, Z, H

## 관측(Measurement)
- 양자컴퓨팅에서는 하나의 양자상태를 측정하면 확률에 따라 하나의 결과가 얻어짐

## 양자성질을 이용한 알고리즘 예시
- 그로버 알고리즘은 비정렬된 데이터베이스에서 특정목표값을 찾는 알고리즘으로서 양자 중첩, 얽힘, 간섭 현상을 활용하여 목표값을 효율적으로 찾아냄

## 여러 가능성 중 정답찾기 문제
- 10개 동전에서 정답을 찾는 경우 그로버 알고리즘 사용시 약 3번 연산으로 정답 도출
- 연산횟수 비교 -> 데이터 규모(N)이 커질수록 양자 컴퓨터의 효율 발생

## 에너지 최소값 찾기
- 에너지 최소값(Ground State) = 최적화 문제
- 문제를 목적 함수로 정의하고 이를 에너지 지형(QUBO/lsing)으로 변환하여 푸는 경우 -> 즉 에너지가 가장 낮은 지점을 찾는 것이 목표임

## 고전 컴퓨팅 해결 방식
- Simulated Annealing
-> 에너지 지형을 따라 비용(에너지)이 감소하는 방향으로 이동하며 확률적인 상태 이동(장벽을 만나면 더 낮은 지점이 있어도 도달하지 못하고 지역 최적해에 머물러 버림)
- 모든 경우의 수를 다 탐색(Brute force)
- 휴리스틱 아록리즘: 효율적인 다양한 탐색 전략을 사용

## 양자 컴퓨팅 해결 방식
- Qunatum Annealing 방식도 초기 상태에는 양자 중첩 성질을 활용하여 모든 경우의 수를 담게 됨
- 그러나 그로버 알고리즘과 같이 오라클과 간섭현상을 이용하는 것이 아닌 양자역학적 단열 진화를 이용해 변화하는 해밀토니안의 바닥상태를 따라가도록 유도함
-> Qunatum Annealing : 최적화에 특화

## 반복되는 주기 찾기 문제
- RSA: 소인수 분해의 계산적 어려움에 기반한, 현대 암호 보안의 대표적인 체계
- 보통 개인키(메시지 해독용)-> 소인수분해 하여 얻은 숫자 기반 결정됨 -> 근데 양자 컴퓨팅이 소인수분해가 가능하다면?
=> 소인수 문제를 효율적으로 해결할 수 있는 가능성을 가짐
- 쇼어 알고리즘(shor Algorithm) 을 통해
- 소인수분해 문제를 양자 역학적 특성을 이용해 주기찾기(period finding)문제로 치환
- 양자 푸리에 변환(QFT)를 이용해 데이터의 반복되는 패턴(주기)를 다항시간 내에 빠르게 추출함

## 분자에너지 계산
- 미지 세계의 양자 현상: 눈에 보이지 않는 미시세계(전자, 원자)는 우리가 아는 물리법칙과 다른 양자역학의 지배를 받음.
- 전자 구조 계산: 전자가 특정 궤도에 존재할 확률 분포
- 에너지 준위 계산: 시스템이 가진 고유한 에너지레벨(바닥상태, 들뜬상태) 추정
- 분자구조 최적화: 에너지가 최소화되는 안정적인 분자 구조 탐색
- 반응 분석: 화학 반응 경로와 에너지 장벽 계산
- 양자 현상이 활용되는 분야 예시
-> 바이오,제약: 단백질 접힘(protein folding)의 예측을 통한 표적 신약 후보 물질 발굴 시간 단축
-> 화학,재료공학: 고효율 배터리 전해질 설계, 나노 물질 시뮬레이션, 탄소 포집 촉매 개발

-> 양자 컴퓨터는 파동함수를 양자상태로 직접 구현하여 고전 컴퓨터의 분자가 커지고 전자 상관관계가 복잡해질 수록 정확한 계산에 필요한 자원을 효율적으로 해결

## 양자 시뮬레이션의 대표알고리즘(VQE)
- 특징: 양자 컴퓨터와 고전 컴퓨터를 함께 사용하는 하입릐드 알고리즘
- 역할: 분자나 물질이 가지는 안정적인 상태(바닥 상태)를 찾아내어 물질의 안정성과 반응성을 예측
- 구동원리
- 1. 양자 프로세서(Ansatz 준비): 분자의 상태를 나타낼 수 있는 양자상태(파동함수)를 큐비트에 구현
- 2. 측정(Energy Measurement): 해당 상태에서 분자가 가진 에너지값을 측정
- 3. 고전컴퓨터(Optimization): 측정된 에너지를 낮출 수 있도록 양자 회로의 변수(파라미터)를 업데이트
- 4. 반복(Loop): 양자컴퓨터로 돌아가 새로운 상태를 생성하고 측정 -> 바닥 상태에 도달할 때까지 반복

## 확률, 기댓값 계산
- 다양한 산업에서 사용, 금융투자, 보험, 제조품질, 에너지, 물류,공급망, 제약, 바이오

## 원주율 추정문제
- 고전 Monte Carlo는 개별 표본의 반복 계산으로 확률을 추정하는 반면, 양자QAE는 중첩상태와 양자 간섭을 활용하여 더 적은 연산 횟수로 확률을 추정할 잠재력을 가짐
- 사각형안에 원을 그리고 점을찍어서 확률을 추정함

## 양자 컴퓨터가 잘하는 문제
- 정답 탐색, 최적화, 숨겨진 규칙, 주기 찾기, 양자계 시뮬레이션, 확률 기댓값 계산
-> 양자컴퓨팅의 이점은 단순히 많은 경울를 동시에 계산하는 것이 아니라, 문제의 구조에 맞게 중첩,얽힘,간섭을 활용해 필요한 계산 자원을 줄이는데 있음

## 양자 컴퓨터가 못하는 문제
- 비구조적 탐색, NP Complete 문제, 단순한 산술논리 연산, 데이터 입출력이 많은 연산
-> 모든 문제를 빠르게 해결할 수 있는 것은 아님, 즉 범용적 "속도 향상 기계" 가 아님

## 양자 컴퓨팅의 가치는 단순한 향상이 아니라 기존에 해결이 어려웠던 핵심 문제를 다룰 수 있다는 점에 있음, 양자 컴퓨팅은 모든 문제를 해결하는 범용기술이 아니라 특정 문제에서 큰가치를 창출하는 전략적 기술

## 양자 컴퓨터의 발전 방향
- ~2000년대
- 1982, Richard Feynmann - 양자컴퓨터 가능성 제시
- 1985, David Deutsch - 최초의 양자 알고리즘 개발
- 1994, Peter Shor - 소인수 분해를 빠르게 해결하는 Shor's Algorithm 개발
- 1996, Lov Grover - 비정렬 데이터 베이스 검색 알고리즘 (Grover's Algoritm)개발
- 2000년대~
- 2001,IBB과 스탠퍼드 대학 - 쇼어 알고리즘 구현성공
- 2011, D-wave 양자 어닐링 방식 - 세계 최초 상용 양자 컴퓨터 출시
- 2019, 구글 - 슈퍼 컴퓨터 연산을 뛰어넘는 양자컴퓨터 'Sycamore' 발표
- 현재, IBM, D-Wave, google, MS 등 주요 기업들 양자 컴퓨터 개발을 가속화 상용화에 한걸음 다가서고 있음
- 2030 즈음 상용화

- 큐비트 수보다 실제 연산 능력을 중시
- IBM은 하드웨어 성능을 Scale(규모), Quality(품질), Speed(속도)라는 세 가지 관점에서 평가
- Nighthawk의 경우 Heron 보다 큐빗수가 적음에도 불구하고 처리량을 크게 계산
- Quantum Advantage 를 FTQC 이전의 독립적인 목표로 설정 : 오류정정 양자 컴퓨터가 완성될때까지 기다리지 않고, 현재의 Noisy Quantum Hardware를 활용하여 고전컴퓨팅 대비 우위를 입증하고자 함
- 모듈형 아키텍처
- 오류정정 기술 개발에 집중
- Quantum-HPC 통합을 최종 컴퓨팅 환경으로 설정

## IQM
- IQM은 양자 컴퓨터를 실제 HPC 환경에 공급하면서, 하드웨어 확장과 오류 정정 기술을 병행하여 2030년 FTQC 구현을 추진하고자함

## IONQ
- IonQ는 양자컴퓨터를 연구실의 고성능 실험장비에서 반도체 산업처럼 반복 생산, 확장할 수 있는 상용 컴퓨팅 시스템으로 전환하고자하며 무엇보다 논리 큐빗의 갯수 증가 공격적인 목표로 갖고 있음

## QuEra
- 중성원자의 물리적 확장성, 병렬 연산 구조, 오류정정 기술을 결합하면서도 기존 HPC 시설에 설치 가능한 시스템을 지향함

## Pasqal
- 아날로그 양자컴퓨팅을 통한 단기 산업적 가치 창출과 Quantum Advantage 실증을 추진하면서, 광집적회로 기반 큐비트 제어, 확장 및 오류 정정 기술을 고도화하여 2029년 FTQC 구현을 목표로함

## 발전 방향
- 물리 큐빗수 중심 -> 오류 정점 중심
- 하드웨어 규모 -> 실행 가능한 계산 규모
- 개별 프로세서 -> 모듈형, HPC 통합
- 기술 개발 중심, 큐빗수, 게이트 충실도, QPU 성능 -> 상용화 중심, 컴퓨팅 접근성, 워크플로 통합, 산업적 가치 지향

## 논리 큐비트
- 논리 큐비트 1개 구현하는데 필요한 물리 큐비트 수는 9개 일 수도 있고, 수백~ 수천 개 이상일 수도 있음
-> 물리 큐빗(오류 발생) -> 논리 큐빗(9개 데이터 큐빗오류 인코딩) -> 오류 탐지 및 정정(보조 큐빗 추가)
- 논리 큐빗 경쟁이 본격화될 수록, 중요한 것은 큐빗수 '몇 개' 가 아니라 '얼마나 빠르고 정확하게'가 중요

## Computational Capability
-> QPU 는 특정 계산에서 고전 컴퓨터를 능가할 수 있는가?
- 성능 경쟁의 기준이 큐빗 수에서 Scale(사용자가 프로그래밍할 수 있는 큐빗수), Quality(게이트 오류율과 회로 깊이), Throughput(일정 시간에 실행하는 회로수)으로 이동 -> 이를 공정하게 비교하는지가 제안됨

## Integrated System
- 핵심은 양자 컴퓨터 혼자 사용하는 것이 아니라, 기존 컴퓨터와 연결해서 하나의 시스템처럼 사용함
- Workflow 등
- 현재 : hardware-led -> 향후: Application-driven

## 양자 컴퓨터의 상용화
- 기술적 임계점: 오류 정정의 완성, 반도체 소자와 같이 소형화, 집적화
- 경제적 임계점: 양자 알고리즘의 "킬러앱"개발, 실제 비즈니스에서 양자 효용성 증명
- 인프라 임계점: 우리가 사용하는 일반적인 소프트웨어/플랫폼의 백엔드에 탑재

- 기반 인프라로서의 양자컴퓨터(Qaas)
- GPU 를 직접 소유하지 않아도 킬러앱(예: 챗GPT)을 사용함으로써 GPU를 사용하게 되는것과 마찬가지로 양자 킬러앱을 사용함으로써 양자 컴퓨터를 소비하는 방식
